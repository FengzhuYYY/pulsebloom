| 文件 | 说明 |
| --- | --- |
| `UnityHubSetup.exe` | Unity Hub 安装程序（约 131 MB，通过 **Git LFS** 托管） |

## 克隆 / Clone

本仓库使用 Git LFS，克隆前请先安装 [Git LFS](https://git-lfs.com/)：

```bash
git lfs install
git clone <repo-url>
```

若克隆时跳过了 LFS 对象，可用：

```bash
git lfs pull
```
